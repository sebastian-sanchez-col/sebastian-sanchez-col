## 🧑‍💻 About me

I'm a Software Engineer with **5+ years of experience** across mobile, web and backend. Most of my
professional work has been **native iOS (Swift, SwiftUI, UIKit)** in a regulated banking environment,
shipping features to an app with **1M+ users**. I've also worked on **Angular/TypeScript micro-frontends**
and on the performance of a **high-throughput notification system (500K+ daily transactions)**.

I care about code that is easy to read, test and change: **SOLID, MVVM / MVVM-C / VIPER, Clean Architecture,
dependency injection and automated testing**. I work closely with Product, Design and QA in Agile/Scrum teams.

- 📱 Native iOS: SwiftUI + UIKit, Combine, async/await, XCTest

- 🤖 I use AI coding assistants (Claude, Copilot/Cursor-style) for research, boilerplate and test drafts, and I review, test and own every change they produce
- 🤝 IT mentor at **ReDI School of Digital Integration** (2026), guiding students toward their first tech jobs
